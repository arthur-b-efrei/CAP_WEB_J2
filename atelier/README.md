à quoi sert Cap Web?
-répondre aux question de l'utilisateur concernant le cinéma indépendant :
-horaire
-film disponible
-résumer des films



comment l'installer et le lancer?
node --version <24.20
cd atelier
npm ci
npm start
npm test

le role des 3 modules dans public/js:
brain.js : Valide le message et choisit la réponse
view.js : affiche l’historique
app.js : relie le formulaire et l’affichage
